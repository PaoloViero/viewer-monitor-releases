# Viewer Monitor Releases

Repository pubblico usato **solo** per l'aggiornamento automatico di Viewer Monitor,
il monitor pubblicitario di EasyCoin. Non contiene codice sorgente: solo
`latest.json` (numero di versione corrente) e, come Release di GitHub, gli
installer firmati.

Deve restare pubblico: i monitor in sala scaricano l'aggiornamento senza
autenticarsi.

Il codice sorgente resta privato nel ramo `viewer-monitor` di
[EasyCoin](https://github.com/PaoloViero/EasyCoin).
